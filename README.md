# 🪙 Coin Collection Game

Unreal Engine 5 + C++로 제작한 코인 수집 게임입니다.

## 📌 게임 소개
제한 시간 안에 맵에 있는 모든 코인을 수집하는 게임입니다.

## 🎮 게임 플레이
- **이동**: WASD
- **점프**: Space
- **재시작**: R

## ⚙️ 개발 환경
- Engine: Unreal Engine 5
- Language: C++
- IDE: Visual Studio 2022

## 🛠️ 구현 기능
- [x] 캐릭터 이동 및 점프
- [x] 코인 Actor (회전 애니메이션)
- [x] 코인 수집 시 사운드 + 파티클 이펙트
- [x] 점수 시스템
- [x] 제한 시간 타이머
- [x] HUD (점수 + 시간 표시)
- [x] Game Clear / Game Over 조건
- [x] R키 재시작 기능
